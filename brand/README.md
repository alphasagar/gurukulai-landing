# GurukulAI brand assets

**Mark: Arch and bindu.** A gurukul gateway arch with a saffron dot (the student, the lamp of learning) inside it.

| File | Use |
|---|---|
| `logo-mark-on-dark.svg` | Mark on ink/dark backgrounds (site nav, footer) |
| `logo-mark-on-light.svg` | Mark on cream/white backgrounds (print, documents) |
| `lockup-on-dark.png`, `lockup-on-light.png` | Mark + "GurukulAI" wordmark, transparent, 1400×400 |
| `app-icon.svg`, `app-icon-1024.png` | Primary app icon (ink tile) for Play Store / app launcher |
| `app-icon-saffron.svg`, `app-icon-saffron-1024.png` | Alternate icon (saffron tile) |
| `favicon.svg`, `favicon-16/32/48/192/512.png` | Browser favicons (heavier stroke for small sizes) |
| `apple-touch-icon.png` | iOS home-screen icon, 180×180 full-bleed |
| `../og-image.png` | Link preview card, 1200×630 |

## Rules

- Colours: ink `#0A0F24`, arch `#EEF0F8` on dark / `#0A0F24` on light, dot `#FFB547` on dark / `#F09A0C` on light.
- Wordmark: "GurukulAI" in Bricolage Grotesque Bold, tracking −3.5%. Mark height ≈ 1.15× the wordmark's cap height.
- Clear space around the mark: at least the dot's diameter on every side.
- Minimum size: 16px (use `favicon.svg` below 48px).
- Don't recolour the dot to anything but saffron, outline the arch, or put the mark on a busy photo without an ink tile.
